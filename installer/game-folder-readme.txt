Feeding Frenzy 2 - Unofficial Remaster
======================================

This folder has the Unofficial Remaster installed. Start the game from Steam as usual.

Settings:     ff2wide.ini (open it with Notepad; every setting is explained there)
Problems:     ff2wide.log has what the Remaster did; include it when you report a bug
Uninstall:    run the Remaster's Setup again and click Uninstall, which puts the original
              game files back (they're kept here as *.original)
Steam:        "Verify integrity of game files" also puts the original FF2.saf back; run
              Setup's Install again afterwards

Co-op (switch it on in the game's Options): player 1 uses the mouse. Everyone else joins
during a level by pressing a button on their own device: a gamepad, a keyboard's W A S D
keys, its arrow keys, or another mouse (up to 4 players on this PC).

Online (set online=1 in ff2wide.ini): up to 9 friends join from their own PCs. Send them
ff2guest.exe from this folder; ff2wide.log shows the address they type in.
